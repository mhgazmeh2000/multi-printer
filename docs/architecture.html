📖 How to use the architecture map

This map shows the complete structure of the Multi-Brand Printer Monitor project in three views. Each node is a real file or module of the project. Click any node to see its Persian description, exact file path, and the list of files it uses and the files that use it.

🏗️ Layer architecture view

It shows the path of data from top to bottom: from the network devices to the SNMP/HTTP → collectors → processing and status → storage → web (Flask) → user browser.

🔄 Data flow view

It explains the complete information-receiving cycle in 13 numbered steps . Press "▶ Play" to light up the steps in order; each step explanation is shown in the side panel. Three "sub-flows" (sensor, OID scan, user actions) are at the bottom of the page.

🧩 File dependency view

60 nodes (all project files + runtime data files + external/test nodes), arranged in columns by folder. An arrow A ─▶ B means "A uses B (import)". Blue dashed lines are HTTP calls from the front end; dotted purple lines are file reads/writes; grey dashed lines are tests.

⬇️ XML export (draw.io)

  • The "XML export" button creates a file multi-printer-architecture.xml that holds all three views on three separate pages.
  • On the app.diagrams.net website (or the draw.io desktop app), open the file via File → Open . All three pages can be edited and exported (PDF/PNG/SVG).

🖱️ Controls

  • Drag the page = move · mouse wheel or ＋/－ buttons = zoom · ⤢ = fit to screen (zoom in when in the dependency view)
  • Hover over a node = highlight all its connections · click a coloured chip at the top of the page = show/hide one group
  • Search works by file name or by Persian name.
